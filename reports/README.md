# Reports

Runtime output directory for `/amazon-analyse {ASIN} {SITE}`.

Do not commit real generated reports to a public repository.

Recommended runtime structure:

```text
reports/{ASIN}_{SITE}_{YYYYMMDD}/
├── {BRAND} {SHORT_PRODUCT_NAME} Listing 全维度穿透分析报告.md
├── raw/
└── {BRAND} {SHORT_PRODUCT_NAME} Listing 全维度穿透分析报告.xlsx
```
